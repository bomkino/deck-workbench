# Contributing

Read README.md, docs/NATIVE_ARCHITECTURE.md and docs/KNOWN_LIMITATIONS.md. Build the native app with npm run build on Apple-Silicon macOS 26+. Keep changes narrow and preserve existing decks. Do not commit client copy, media, local decks or credentials. Behavioural checks must prove a user-visible outcome, not a particular implementation shape. The September 2026 user-test promotion waives acceptance testing for that release only; do not silently generalise that waiver.
