# Contributing

Read README.md, docs/NATIVE_ARCHITECTURE.md and docs/KNOWN_LIMITATIONS.md. Build the native app with npm run build on an Apple-Silicon Mac running macOS 26, with Xcode (the macOS 26 SDK) and Node.js 24+. Before a pull request, run what CI runs, in its order: npm test, npm run verify:indesign, npm run build, npm run verify:package, the UI gallery and npm run test:update (README.md → Build and maintain). The build refuses uncommitted or untracked sources, so commit first. Keep changes narrow and preserve existing decks. Do not commit client copy, media, local decks or credentials. Behavioural checks must prove a user-visible outcome, not a particular implementation shape. The September 2026 user-test promotion waives acceptance testing for that release only; do not silently generalise that waiver.
