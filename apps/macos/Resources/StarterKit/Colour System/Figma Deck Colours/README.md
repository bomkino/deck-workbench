# Deck Colours — shared Figma Tool

Use the existing **[pitch.dog master starter](https://www.figma.com/design/lfle8qchYjg0O0VgCZGXnK/)**. Duplicate the whole file for a project, then choose its 2576 × 1080 or 1920 × 1080 working page.

Open **Tools → Deck Colours → Created by you → Run**. This Tool lives in the shared Figma account; no development-plugin import is needed on another Mac.

1. Choose the role to change: neutral base, Primary, Secondary, Third, Fourth or Mono.
2. Pick by sight from the labelled colour swatches. The selection is marked.
3. Check the dark and light previews, then Apply.
4. Use **Restore previous** to return to the previous palette.

Each slide keeps its own dark/light appearance. Existing files retain their saved colours until you Apply. Choose the same base and families in Workbench or InDesign when coordinating an existing project; edits in Figma do not back-sync into those applications.

**PD House:** the optional **Set up PD House styles** action creates a separate house style group/specimen for internal route and exploration slides. Install the three supplied **Fonts/PD House** variable fonts first. This does not change the project's typography or InDesign styles. Project and House typography are deliberately independent.

The existing Workbench to Figma and Text Scramble Tools remain separate and unchanged. The older duplicate file was used to test the importer; it is not the master starter for future projects.

Account Tool ID: `21b74b40-257e-4b4a-8357-b0b87a762148`. Its current source/version can be read from the shared account Tool editor. The master uses the frozen `pitchdog-colours/1` library supplied beside this guide. The PD House adaptation retains the starter's slide sizes/leading and uses font roles from type-system v13.1.1, commit `318e6ff4d4bf76be76f7ed5225aacf7517d2ee82`; it does not add global type-system roles.

Contrast samples describe solid colour pairs. Recheck text placed over photos, gradients or transparency.
