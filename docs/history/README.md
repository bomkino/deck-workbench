# History

Earlier plans, specifications, tickets, audits and release evidence, kept as they were written. They describe earlier milestones (including the retired browser and Linux work) and are not current instructions. The current guides are in [docs](../README.md).

- `product/`, `architecture/`, `implementation/`, `03-build/` — earlier specifications, contracts and tickets.
- `evidence/` — audits and acceptance records for the builds they name; never rewritten to imply new verification.
- `releases/` — notes for early releases; later releases are in [RELEASE_NOTES.md](../RELEASE_NOTES.md).
- `agent/` — the earlier project log.
- `WORKBENCH_PARITY_PLAN.md` — the plan for reaching parity with the earlier prototyper.
