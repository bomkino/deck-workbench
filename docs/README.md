# Current documentation

Start with README.md and these current guides:

- MAC_APP.md — import, curate, assemble, export and recovery. README.md lists the keyboard shortcuts; Help → Keyboard Shortcuts shows them in the app.
- KNOWN_LIMITATIONS.md — tested boundaries and unresolved scope.
- NATIVE_ARCHITECTURE.md — current owners and implementation decisions.
- UPDATES.md — getting updates in the app, the signed release feed and how to publish a release.
- RELEASE_NOTES.md — what changed in each version since v0.1.3, newest first. Earlier versions' notes are on their [GitHub release pages](https://github.com/bomkino/deck-workbench/releases).
- examples/native-copy.md — bounded Markdown import example.

Older product, architecture, ticket and audit documents are in [history](history/README.md). They describe earlier milestones and remain historical evidence, not current operating instructions. Release evidence belongs to the exact build artifact; never rewrite past results to imply new verification.
