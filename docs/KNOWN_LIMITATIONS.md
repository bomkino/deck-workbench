# Known boundaries — current source

Apple Silicon and macOS 26+ only. Ad-hoc signed, not notarized. The application is a prototype/intent tool, not final production design software.

These docs describe implemented behaviour, not release, installation or native Adobe acceptance. The package journey launches the extracted Mac app and exercises synthetic document/edit/export cases; inspect the receipt for the exact build SHA and checks actually completed. A passing encoder readback or scripted journey does not prove Photoshop shared-object editing, InDesign placement, every user path or a finished design.

Still requiring hands-on evaluation: VoiceOver and full keyboard navigation of every native control, including the redesigned workspace (its screens are checked from CI screenshots, not by hand on a studio Mac). Known gaps: the canvas is a single accessibility element; resizing a frame, panning a crop and moving gradient end points are pointer gestures (the inspector offers nudges, presets, Centre crop and zoom instead); media focus in the grid is drawn rather than a real keyboard focus, so it is announced to VoiceOver instead. Also unevaluated: all display/window/scaling combinations; large real media libraries on studio machines; network/removable/cloud-managed folders and permission recovery; every supported source codec. Performance counters are evidence from a synthetic hosted-Mac workload, not a blanket speed multiplier.

Import accepts UTF-8 Markdown/text up to 1 MiB, including Workbench Markdown v1; it does not convert DOCX/PDF. Replacement maps existing slides without automatically adding, removing or reordering them. Manual add, duplicate, rename (slides, parts and the deck), move and confirmed delete are available from the Slide menu/sidebar. The deck must retain at least one slide. Candidate comparison supports three items; a moodboard supports up to 12 chosen image slots. Ratings/project-wide picks remain secondary legacy metadata.

Contents is a derived two-column list of included slide names, not a separately editable copy field. It excludes contents entries, recalculates page references for the chosen export, wraps long titles and reports overflow. It does not automatically create continuation index pages. Its two-column layout overrides the general Columns control. Changing a moodboard's slot count resets its grid frames; displaced images stay shortlisted.

Slide typography uses installed fonts and paired size/leading presets. Missing fonts use a flagged system-font fallback; coverage, shaping, wrapping and image contrast require visual review. **Fit copy within readable limits** can reduce the requested type size. Appearance/palette controls apply to native layouts; preserved legacy compositions require conversion. The existing bundled FontBlind v13.0.0 pin is unchanged.

The colour library supplies paired RGB choices and contrast ratios for flat text/background combinations. It does not certify text over artwork or arbitrary custom pairings, and it is not a CMYK print-proofing system. Saved palettes contain literal hex values, so a library update never recolours an existing deck. Production JSON carries palettes and text colour roles; workbench.md alone does not. The supplied InDesign builder is needed to apply those colours automatically.

Legacy compositions preserve supported text/image/gradient data; their old typography and unsupported shapes are not an exact reproduction guarantee. Convert deliberately and keep the original. Very dense copy can overflow a prototype at the lower type limit; complete text is retained in copy/notes companions when selected. PDFs represent GIF/video as a still frame, and PDF media as its first page; original files remain intact in media handoff.

Production Markdown represents Headline, Subheadline and Body. Repeated or extra roles are grouped with paragraph breaks and a warning; the manifest retains the ordered fields, identities, state and mapping. Missing copy remains unreviewed, which older InDesign/Figma importers may display as a dash. Imported writing does not recreate Workbench layouts or live contents. Whitespace-only present copy, unsupported control characters, contradictory states or invalid single-line metadata block Production rather than silently changing text; Copy.md can still retain it. Production supports 1–1000 slides and at most 1 MiB of Markdown, matching Workbench’s own intake limit. Export smaller selections for unusually large decks.

PSD export supports only **1920 × 1080** and **2576 × 1080**, in RGB/8-bit sRGB, with up to 12 image placements per slide. It runs one slide at a time and rejects slides exceeding 128 MiB of combined source bytes or the 768 MiB estimated working-memory budget. The estimate is a guard, not a measured peak-memory guarantee. On another canvas, the PSD option is disabled; production writing, PDFs and original media remain available.

PSDs carry editable artwork and guides, not prototype text, background colour or gradients. Workbench framing uses editable masks by default. Optional full-image export disables those masks and can reveal artwork beyond the Workbench frames; embedded JPEG/PNG/TIFF sources remain complete in either mode. Document canvas bounds still limit the visible composite, without deleting the embedded source pixels. **00.Background** and **01.Character** initially show the same full artwork through one shared embedded source. They are not automatic background/subject extractions. The artist creates the cut-out/mask in Photoshop before using the bundled artwork-only PNG role exporter. The hidden text guide (the slide copy as Workbench sets it, over its text boxes) is editing assistance only: a static picture of the type, not editable Photoshop text, and its fonts and wrapping are Workbench's. The PNG script cleans it in a temporary PSD copy; unsupported linked layered objects or nesting fail clearly. Native Photoshop checks covered shared-source edits, save/reopen, JPEG orientation and transparent role export using synthetic files. Review actual project media and final InDesign placement separately.

Supported single-image JPEG, PNG and TIFF bytes are embedded unchanged; other supported image formats, animated media, video and PDFs use an explicitly reported still/first image or page in the PSD, at up to 3072 px. The visible artwork in PSDs and the prototype PDF is decoded at the size it is placed (up to 8192 px, never above the original); a slide whose artwork would exceed the export's memory budget is decoded smaller and reported, with the originals unchanged. Select Approved Media/Shortlisted Media to retain the external originals as well. An assigned source that is missing, changed without consent, unsupported or too large can fail Production. Empty unassigned slots remain editable placeholders and are reported.

Media sizes, scan depth/count, preview decoding and import/command payloads remain bounded. A folder is catalogued up to 12,000 media files; Workbench says when a folder holds more. Camera RAW files are not catalogued. An external drive that mounts with a different device number can ask for its folder to be reconnected; reconnecting keeps every decision. Unsupported previews do not imply that an original cannot be handed off. Partial component failures are shown; requested production writing/manifest/PSDs succeed or fail together, while independently completed copy, media and PDFs remain available. Cancelled exports discard unfinished staging; a hidden staging folder left by a crash or force quit is removed by a later export to the same folder once it is at least two hours old (a day on network volumes) and no export holds it. A Copy.md over the 1 MiB import limit is still written and reported. Once the handoff is saved, cancelling an optional InDesign build retains it and reports any incomplete Adobe output. Existing handoff folders and source media are not overwritten.

Undo keeps the last 500 steps within about 32 million characters of history, so deck-wide changes on very large decks keep fewer. A deck saved with an undo step its version could never apply opens without that step and the older ones. Recover Saved Copy repairs damaged journal lines, but not a journal whose actions a later version refuses to replay; new validation applies only to new actions so that this does not arise. Older Workbench versions cannot open an upgraded deck and Undo does not downgrade it; [Recovery](MAC_APP.md#recovery) explains when a deck is upgraded and how to keep a copy for an older app. No multi-writer/cloud collaboration or notarization is included. In-app updates (Sparkle) reach copies from v0.5.0 onward; v0.4.0 and earlier must be replaced by hand once. The local signed-feed update test runs in CI for every change. A live update between published releases is proven only by the release workflow, which updates a copy of the current Latest release from the new release's own feed before making it Latest; the first such update, 0.5.0 to 1.0.0, is proven when that step passes for v1.0.0 (see its run log).

Native window captures support visual review; they are not an exhaustive accessibility or all-display guarantee. External-volume/cloud-provider cancellation and rare post-journal failure handling still need real-environment evaluation. Crop zoom is limited to 4× and commits when the slider gesture finishes.

Automatic InDesign is optional and requires an installed InDesign application, the starter fonts and macOS Automation permission. Workbench copies the complete kit and builds only a new destination. It verifies the saved document receipt, page count and two PSD placements per page. A long build may run past InDesign's one-hour reply; Workbench keeps waiting for its receipt for at least two hours (an hour plus a minute per slide), and stops when InDesign quits or the build is cancelled. InDesign/Links/PSD and Production/PSD are independent copies; edit the folder for your destination app. Run Refresh PSD Links after a move or returned artwork. InDesign copy takes its starter paragraph styles; imported layouts are a starting point, not exact reproduction of every Workbench text frame/font/gradient. The imported index is a static snapshot of the exported order.
