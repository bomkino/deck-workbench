# Known boundaries — v0.4.0 implementation

Apple Silicon and macOS 26+ only. Ad-hoc signed, not notarized. The application is a prototype/intent tool, not final production design software.

These docs describe implemented behaviour, not release, installation or native Adobe acceptance. The package journey launches the extracted Mac app and exercises synthetic document/edit/export cases; inspect the receipt for the exact build SHA and checks actually completed. A passing encoder readback or scripted journey does not prove Photoshop shared-object editing, InDesign placement, every user path or a finished design.

Still requiring hands-on evaluation: VoiceOver and full keyboard navigation of every native control; all display/window/scaling combinations; large real media libraries on studio machines; network/removable/cloud-managed folders and permission recovery; every supported source codec. Performance counters are evidence from a synthetic hosted-Mac workload, not a blanket speed multiplier.

Import accepts UTF-8 Markdown/text up to 1 MiB, including Workbench Markdown v1; it does not convert DOCX/PDF. Replacement maps existing slides without automatically adding, removing or reordering them. Manual add, duplicate, rename, move and confirmed delete are available from the Slide menu/sidebar. The deck must retain at least one slide. Candidate comparison supports three items; a moodboard supports up to 12 chosen image slots. Ratings/project-wide picks remain secondary legacy metadata.

Contents is a derived two-column list of included slide names, not a separately editable copy field. It excludes contents entries, recalculates page references for the chosen export, wraps long titles and reports overflow. It does not automatically create continuation index pages. Its two-column layout overrides the general Columns control. Changing a moodboard's slot count resets its grid frames; displaced images stay shortlisted.

Slide typography uses installed fonts and paired size/leading presets. Missing fonts use a flagged system-font fallback; coverage, shaping, wrapping and image contrast require visual review. Fit Copy can reduce the requested type size. Appearance/palette controls apply to native layouts; preserved legacy compositions require conversion. The existing bundled FontBlind v13.0.0 pin is unchanged.

The colour library supplies paired RGB choices and contrast ratios for flat text/background combinations. It does not certify text over artwork or arbitrary custom pairings, and it is not a CMYK print-proofing system. Saved palettes contain literal hex values, so a library update never recolours an existing deck. Production JSON carries palettes and text colour roles; workbench.md alone does not. The supplied InDesign builder is needed to apply those colours automatically.

Legacy compositions preserve supported text/image/gradient data; their old typography and unsupported shapes are not an exact reproduction guarantee. Convert deliberately and keep the original. Very dense copy can overflow a prototype at the lower type limit; complete text is retained in copy/notes companions when selected. PDFs represent GIF/video as a still frame, and PDF media as its first page; original files remain intact in media handoff.

Production Markdown represents Headline, Subheadline and Body. Repeated or extra roles are grouped with paragraph breaks and a warning; the manifest retains the ordered fields, identities, state and mapping. Missing copy remains unreviewed, which older InDesign/Figma importers may display as a dash. Imported writing does not recreate Workbench layouts or live contents. Whitespace-only present copy, unsupported control characters, contradictory states or invalid single-line metadata block Production rather than silently changing text; Copy.md can still retain it. Production supports 1–1000 slides and at most 1 MiB of Markdown, matching Workbench’s own intake limit. Export smaller selections for unusually large decks.

PSD export supports only **1920 × 1080** and **2576 × 1080**, in RGB/8-bit sRGB, with up to 12 image placements per slide. It runs one slide at a time and rejects slides exceeding 128 MiB of combined source bytes or the 768 MiB estimated working-memory budget. The estimate is a guard, not a measured peak-memory guarantee. On another canvas, the PSD option is disabled; production writing, PDFs and original media remain available.

PSDs carry editable artwork and guides, not prototype text, background colour or gradients. Workbench framing uses editable masks by default. Optional full-image export disables those masks and can reveal artwork beyond the Workbench frames; embedded JPEG/PNG/TIFF sources remain complete in either mode. Document canvas bounds still limit the visible composite, without deleting the embedded source pixels. **00.Background** and **01.Character** initially show the same full artwork through one shared embedded source. They are not automatic background/subject extractions. The artist creates the cut-out/mask in Photoshop before using the bundled artwork-only PNG role exporter. A hidden 50% text-area guide is editing assistance only. The PNG script cleans it in a temporary PSD copy; unsupported linked layered objects or nesting fail clearly. Native Photoshop checks covered shared-source edits, save/reopen, JPEG orientation and transparent role export using synthetic files. Review actual project media and final InDesign placement separately.

Supported single-image JPEG, PNG and TIFF bytes are embedded unchanged; other supported image formats, animated media, video and PDFs use an explicitly reported still/first image or page in the PSD. Cached previews can be downsampled; select Approved Media/Shortlisted Media to retain the external originals as well. An assigned source that is missing, changed without consent, unsupported or too large can fail Production. Empty unassigned slots remain editable placeholders and are reported.

Media sizes, scan depth/count, preview decoding and import/command payloads remain bounded. Unsupported previews do not imply that an original cannot be handed off. Partial component failures are shown; requested production writing/manifest/PSDs succeed or fail together, while independently completed copy, media and PDFs remain available. Cancelled exports discard unfinished staging. Once the handoff is saved, cancelling an optional InDesign build retains it and reports any incomplete Adobe output. Existing handoff folders and source media are not overwritten.

New packages use schema 3. Workbench 0.1.3 and earlier reject them. Opening an older deck alone does not upgrade it; saving starter features or explicit copy-field states verifies internal pre-upgrade recovery data before promoting the working package. Undo does not downgrade the schema, and internal backup files are not a standalone old-app deck. Keep an untouched duplicate for older versions. A first ordinary native edit of a pre-native schema-1 package can still require the earlier schema-2 upgrade. No multi-writer/cloud collaboration, automatic updates or notarization is included.

Native window captures support visual review; they are not an exhaustive accessibility or all-display guarantee. External-volume/cloud-provider cancellation and rare post-journal failure handling still need real-environment evaluation. Crop zoom is limited to 4× and commits when the slider gesture finishes.

Automatic InDesign is optional and requires an installed InDesign application, the starter fonts and macOS Automation permission. Workbench copies the complete kit and builds only a new destination. It verifies the saved document receipt, page count and two PSD placements per page. InDesign/Links/PSD and Production/PSD are independent copies; edit the folder for your destination app. Run Refresh PSD Links after a move or returned artwork. InDesign copy takes its starter paragraph styles; imported layouts are a starting point, not exact reproduction of every Workbench text frame/font/gradient. The imported index is a static snapshot of the exported order.
