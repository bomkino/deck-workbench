# Native interface direction

Prefer stable native Mac controls, visible slide context, keyboard-complete curation, modest provisional type, and a dominant Assembly canvas. Preserve exact copy and image decisions; do not add a production typography system. Grid baseline: 2576 x 1080, 24 columns / 12 rows, margins 96 / 64 and gutters 16 / 8 canvas units. User layouts remain suggestions for designers. See docs/NATIVE_ARCHITECTURE.md.
